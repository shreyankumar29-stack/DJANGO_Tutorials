# 🛠️ Commands Used

## Create Virtual Environment

```bash
python -m venv .venv
```

## Activate Virtual Environment

### PowerShell

```powershell
.venv\Scripts\Activate.ps1
```

### Command Prompt

```cmd
.venv\Scripts\activate
```

---

## Install Django

```bash
pip install django
```

---

## Verify Installation

```bash
django-admin --version
```

---

## Create Project

```bash
django-admin startproject django_project .
```

---

## Run Development Server

```bash
python manage.py runserver
```


---

# 📌 Files Overview

| File | Purpose |
|------|---------|
| manage.py | Command-line utility used to manage the Django project. |
| settings.py | Contains all project configurations and settings. |
| urls.py | Defines URL routes for the project. |
| asgi.py | Entry point for asynchronous applications (ASGI). |
| wsgi.py | Entry point for traditional synchronous deployment (WSGI). |
| __init__.py | Marks the directory as a Python package. |

---

# 🎯 Key Takeaways

- Django automatically generates the initial project structure.
- Every Django project contains configuration files.
- The development server is started using `manage.py`.
- Virtual environments keep project dependencies isolated.
- `asgi.py` supports asynchronous applications.
- `wsgi.py` is used for traditional deployment.
