# Part 02 - Commands Reference

This file contains all the commands used in Part 02 of the Django tutorial series.

---

# Create a Django App

```bash
python manage.py startapp blog
```

Creates a new Django application named **blog**.

---

# Run Development Server

```bash
python manage.py runserver
```

Starts the Django development server.

---

# Run Server on a Custom Port

```bash
python manage.py runserver 8001
```

Runs the server on port 8001.

---

# Stop Development Server

```text
CTRL + C
```

Stops the running server.
